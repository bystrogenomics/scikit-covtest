\subsection{Size and Power with MNIST}
\label{sec:mnist-example}

We use the MNIST handwritten-digit dataset~\citep{lecun2002gradient} as a
high-dimensional, non-Gaussian illustration of two-sample covariance testing.
Each image is represented by $28 \times 28 = 784$ pixel intensities. We combine
the training and test splits, scale pixel intensities to $[0,1]$ using the
dataset loader, and then standardize each pixel separately within the digit-0
and digit-1 samples. Values above 10 after standardization are truncated to
10. This preprocessing focuses the comparison on differences in within-class
correlation structure rather than marginal location and scale.

We compare the Srivastava (2007) and Srivastava--Yanagihara (2014) two-sample
covariance tests. For null calibration, each of 300 replications draws $2N$
distinct digit-0 images without replacement and partitions them into two
nonoverlapping samples of size $N = 200$. For the alternative, one sample of
$N$ digit-0 images and one independently drawn sample of $N$ digit-1 images
are compared. All replications use \code{np.random.default_rng(0)}. The
complete analysis and figure-generation code are provided in
\code{figures/run\_mnist\_example.py}.

\begin{CodeChunk}
\begin{CodeInput}
>>> import numpy as np
>>> from sklearn.preprocessing import StandardScaler
>>> from covtest.datasets import load_mnist
>>> from covtest.methods.hypothesis_two_sample import (
...     srivastava_two_sample_2007,
...     srivastava_yanagihara_two_sample,
... )
>>> N, n_rep = 200, 300
>>> X_tr, y_tr = load_mnist(split="train")
>>> X_te, y_te = load_mnist(split="test")
>>> X = np.concatenate((X_tr, X_te))
>>> y = np.concatenate((y_tr, y_te))
>>> X0 = StandardScaler().fit_transform(X[y == 0])
>>> X1 = StandardScaler().fit_transform(X[y == 1])
>>> X0[X0 > 10] = 10
>>> X1[X1 > 10] = 10
>>> methods = [
...     srivastava_two_sample_2007,
...     srivastava_yanagihara_two_sample,
... ]
>>> rng = np.random.default_rng(0)
>>> null_pvalues = np.empty((n_rep, len(methods)))
>>> alternative_pvalues = np.empty_like(null_pvalues)
>>> for i in range(n_rep):
...     idx0 = rng.choice(X0.shape[0], size=2 * N, replace=False)
...     idx1 = rng.choice(X1.shape[0], size=N, replace=False)
...     for j, method in enumerate(methods):
...         null_pvalues[i, j] = method(X0[idx0[:N]], X0[idx0[N:]])["p_value"]
...         alternative_pvalues[i, j] = method(X0[idx0[:N]], X1[idx1])["p_value"]
\end{CodeInput}
\end{CodeChunk}

Figure~\ref{fig:mnist} summarizes the input distributions, null calibration,
and empirical rejection rates at $\alpha = 0.05$. The pixel-intensity
distributions are strongly non-Gaussian, with substantial mass near zero and a
right-skewed positive tail. Under the digit-0 versus digit-0 null, the
empirical rejection rates are 0.023 for Srivastava (2007) and 0.003 for
Srivastava--Yanagihara (2014). Thus, both procedures are conservative in this
non-Gaussian design, particularly the latter. Under the digit-0 versus
digit-1 comparison, the corresponding empirical rejection rates are 0.687 and
1.000. These results illustrate that the two methods can detect marked
differences in the covariance structure of the two digit classes, while also
showing the importance of checking null calibration when applying large-sample
procedures to structured, non-Gaussian image data.

\begin{figure}[t!]
\centering
\includegraphics[width=\textwidth]{figures/figure_mnist.pdf}
\caption{\label{fig:mnist} MNIST two-sample covariance-test results for
digit 0 versus digit 1. The left panel shows the standardized pixel-intensity
distributions. The middle panel presents P--P plots for the digit-0 versus
digit-0 null comparison. The right panel reports empirical rejection rates at
$\alpha = 0.05$ under the null and under the digit-0 versus digit-1
alternative, based on 300 replications with $N = 200$ observations per group.}
\end{figure}

\subsection{Multiple Hypothesis Testing with TCGA}
\label{sec:tcga-example}

This worked example demonstrates a reproducible pathway-level workflow in
\pkg{scikit-covtest}; it is not intended as a confirmatory biological analysis.
We use the gene-expression cancer RNA-Seq dataset~\citep{fiorini2016gene}, a
random extraction from the RNA-Seq (HiSeq) PANCAN dataset assembled by The
Cancer Genome Atlas Pan-Cancer Analysis Project~\citep{weinstein2013cancer}.
The dataset contains 801 samples and 20,531 gene-expression features. We
compare breast invasive carcinoma (BRCA, $n = 300$) with lung adenocarcinoma
(LUAD, $n = 141$).

The first column returned by \code{load_tcga()} is a sample identifier and is
removed before the expression matrix is converted to numeric form. The
distributed matrix has placeholder feature labels, so the accompanying PanCan
identifier map restores source gene identifiers in their original column
order. We intersect those identifiers with the versioned human Reactome GMT
file distributed with the repository. We retain Reactome pathways containing
15--100 unique matched genes, yielding 1,152 eligible pathways.

Within each tumour type, the script applies \code{StandardScaler} to every
gene before testing: nonconstant genes are centered and scaled to unit
variance, whereas a constant feature remains zero. Thus, the example
illustrates comparisons of standardized within-pathway covariance structure
rather than a raw-covariance analysis. For each eligible pathway, we apply the
Srivastava (2007) two-sample
statistic and report its analytic $p$-value together with nominal Bonferroni,
Benjamini--Hochberg (BH), and Benjamini--Yekutieli (BY) adjusted summaries.
The complete workflow and its input-file checksums are provided in
\code{figures/run\_tcga\_example.py}.

\begin{CodeChunk}
\begin{CodeInput}
>>> import numpy as np
>>> from sklearn.preprocessing import StandardScaler
>>> from covtest.datasets import load_tcga
>>> from figures.run_tcga_example import read_pathways, test_pathways
>>> X_raw, y = load_tcga()
>>> X = X_raw[:, 1:].astype(float)  # Drop the sample-ID column.
>>> pathways = read_pathways(X.shape[1], minimum=15, maximum=100)
>>> X_brca = StandardScaler().fit_transform(X[y == "BRCA"])
>>> X_luad = StandardScaler().fit_transform(X[y == "LUAD"])
>>> rows = test_pathways(X_brca, X_luad, pathways)
>>> len(rows)
1152
\end{CodeInput}
\end{CodeChunk}

For the current inputs, Reactome \emph{Surfactant metabolism}
(R-HSA-5683826; 28 matched genes) has the smallest analytic $p$-value
($4.74 \times 10^{-11}$; statistic $=43.28$), and is the only pathway below
all three nominal adjusted thresholds (BH $q = 5.45 \times 10^{-8}$; BY
$q = 4.16 \times 10^{-7}$). In this worked example, these values are used to
illustrate pathway ranking and multiplicity-adjustment APIs. They are not
presented as a validated scientific discovery or as evidence for an individual
gene, a causal mechanism, or a therapeutic target.

We assess the finite-sample behavior of the analytic reference distribution in
a diagnostic null simulation. For each of the 85 pathway dimensions occurring
in the analysis, 1,000 BRCA-sized and LUAD-sized Gaussian samples are generated
from the same AR(1) correlation matrix with $\rho = 0.5$, standardized within
group, and passed through the same test pipeline. At nominal $\alpha = 0.05$,
the observed rejection proportions range from 0 to 0.001 rather than
approximately 0.05. Thus, the analytic $p$-values are strongly conservative in
this simulated setting.

This diagnostic does not establish calibration for TCGA data, other covariance
structures, or non-Gaussian expression distributions. Accordingly, the
Bonferroni, BH, and BY values are reported as conventional nominal adjustment
summaries, not as empirically validated 5\% FWER or FDR guarantees.
Non-rejection should not be interpreted as evidence of equal standardized
within-pathway covariance structure. The simulation and pathway results can be
reproduced with
\code{python figures/run\_tcga\_example.py --calibration-reps 1000 --seed 42}.
